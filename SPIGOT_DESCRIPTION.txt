[SIZE=5][B]» Information[/B][/SIZE]
AdvancedLobby is a free and fully customizable lobby plugin for your Minecraft server.
This is an updated version of the original AdvancedLobby by [B]cyne[/B], rewritten to run on Minecraft 1.17 – 26.3 (Spigot & Paper) – one jar for all versions. All credits for the original plugin go to cyne.

Currently, there are no ranks and no scoreboard implemented into the lobby plugin. Feel free to use any other plugin for ranks and the scoreboard.

[SIZE=5][B]» Requirements[/B][/SIZE]
• Minecraft [B]1.17 – 26.3[/B] (Spigot / Paper and forks)
• Java: [B]16+[/B] for 1.17, [B]17+[/B] for 1.18 – 1.20.4, [B]21+[/B] for 1.20.5 – 1.21.x, [B]25[/B] for 26.x
• [URL='https://www.spigotmc.org/resources/6245/']PlaceholderAPI[/URL] (optional, needed for placeholders)

[B]Tested on Paper:[/B] 1.17.1, 1.18.2, 1.19.4, 1.20.4, 1.20.6, 1.21.1, 1.21.4, 1.21.10, 26.2, 26.3

[B]Note:[/B] Minecraft 1.8 – 1.16 is not supported by this version. Use the original plugin for those versions.

[SIZE=5][B]» Installation[/B][/SIZE]
1. Put the plugin file into the [I]plugins[/I] folder of your server
2. Restart your server
3. Set your spawn and teleporter locations with [I]/al location[/I]
4. Customize everything in [I]config.yml[/I], [I]messages.yml[/I] and [I]sounds.yml[/I]
5. Apply your changes with [I]/al reload[/I]

[SIZE=5][B]» Features[/B][/SIZE]
[B]Hotbar items[/B]
• Teleporter (customizable navigator menu)
• Player hider (show all / show VIP / show none)
• Cosmetics menu
• Gadget slot
• Silent lobby
• Shield
• Custom item

[B]Cosmetics[/B]
• Hats: Melon, TNT, Glass, Sponge, Pumpkin, Cactus
• Particles: Hearts, Music, Flames, Villager, Rainbow
• Balloons: Yellow, Red, Green, Blue, Hay block, Sea lantern, Bookshelf, Note block
• Gadgets: Grappling hook, Rocket jump

[B]Lobby[/B]
• Integrated MultiWorld mode (multiple lobby worlds)
• Jump pads
• Void teleport
• World border
• Weather lock
• Command blocker
• Join settings (gamemode, health, clear inventory, spawn teleport)
• Protection: no block breaking/placing, no damage, no hunger, no item drops & more (unless in build mode)

[B]Display[/B]
• Join title & subtitle
• Actionbar messages
• Tablist header & footer
• Custom MOTD
• Chat format
• Supporting PlaceholderAPI

[SIZE=5][B]» Changelog[/B][/SIZE]
[B]2.1[/B]
• Support for Minecraft 1.17 – 26.3 in a single jar
• Skull textures, item flags, max health and particles work on old and new versions

[B]2.0.1[/B]
• Fixed a NullPointerException on player join on Paper servers

[B]2.0[/B]
• Full support for Minecraft 26.3 & Java 25
• Removed all NMS code – titles, actionbar, tablist, particles and skulls now use the official API
• Old particle names in configs are converted automatically
• Sounds can be set by name (ENTITY_PLAYER_LEVELUP) or key (minecraft:entity.player.levelup)
• Volume & pitch support decimal values
• Async update checker
